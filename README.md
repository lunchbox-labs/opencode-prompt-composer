# Prompt Composer

Share reusable prompt text across native agents, commands and on-demand skills with explicit inline includes, in OpenCode and Kilo CLI.

| Host | Package |
| --- | --- |
| OpenCode | [`@lunchbox-labs/opencode-prompt-composer`](packages/opencode/) |
| Kilo CLI | [`@lunchbox-labs/kilo-prompt-composer`](packages/kilo/) |

Both packages are built from the shared source in [`packages/core`](packages/core/), which the build bundles into each of them; it is not published on its own. Each package README shows how to install it, and the [wiki](https://github.com/lunchbox-labs/prompt-composer-plugin/wiki) has the full guides.
