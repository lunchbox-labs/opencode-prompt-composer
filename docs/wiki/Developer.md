# Developer documentation

For contributors and maintainers working on Prompt Composer:

- [Development](Development): local builds, runtime boundaries and compatibility checks.
- [Publishing](Publishing): trusted publisher setup and the release workflow.
- [Extraction provenance](Extraction-provenance): origin of the include engine.

The plugin's state machines are documented in [docs/state-machines.md](https://github.com/lunchbox-labs/opencode-prompt-composer/blob/main/docs/state-machines.md). These wiki pages are published from [docs/wiki](https://github.com/lunchbox-labs/opencode-prompt-composer/tree/main/docs/wiki) on every push to `main`; change them there.

The repository's [AGENTS.md](https://github.com/lunchbox-labs/opencode-prompt-composer/blob/main/AGENTS.md) and linked shared standards remain the authoritative machine instructions. Runnable examples and the license stay in the repository and published package. [User documentation](Home#user-documentation) covers installation and everyday use.
