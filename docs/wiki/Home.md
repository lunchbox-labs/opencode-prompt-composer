# Prompt Composer

Share reusable text across native agents, commands and on-demand skills with explicit inline includes, in OpenCode and Kilo CLI. These guides describe the current repository; published packages may differ.

| Host | Package | Versions |
| --- | --- | --- |
| OpenCode | `@lunchbox-labs/opencode-prompt-composer` | [npm](https://www.npmjs.com/package/@lunchbox-labs/opencode-prompt-composer?activeTab=versions) |
| Kilo CLI | `@lunchbox-labs/kilo-prompt-composer` | [npm](https://www.npmjs.com/package/@lunchbox-labs/kilo-prompt-composer?activeTab=versions) |

Both packages behave the same way and are released together at one version. They differ only in the host's configuration directories, environment variables and product name.
