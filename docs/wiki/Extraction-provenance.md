# Extraction provenance

Prompt Composer's include safety engine and dialog navigation originated in the MIT-licensed [Config Composer](https://github.com/lunchbox-labs/opencode-config-composer) project. The packages now have separate responsibilities: configuration composition belongs to Config Composer; inline prompt inclusion belongs to Prompt Composer.

The current runtime and compatibility boundaries are documented in [Development](Development). Consumer migration guidance is in [Migration](Migration). Historical implementation decisions remain in the repositories' issues, pull requests and git history.
